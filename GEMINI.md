# Adaptador para Gemini CLI

O import acima é a fonte canônica do projeto. Não duplique regras neste arquivo.

- Execute a CLI a partir da raiz do repositório.
- Use `/memory show` para conferir o contexto e `/memory reload` após editar
  este arquivo ou `AGENTS.md`.
- Respeite `.geminiignore`, `.gitignore` e os limites de dados locais definidos
  nas instruções canônicas.
- Não crie memória privada, configurações globais ou políticas fora do
  repositório sem solicitação explícita.
